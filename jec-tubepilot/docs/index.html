What TubePilot does

  • Listens to the song (uploaded file or public link) with Gemini: style, rhythm and tempo (BPM, meter, maqam), dialect, chorus, lyrics, 2–5 best moments. Built for every music of the world: khaliji, sheilat, Iraqi rap, Yemeni, Egyptian, Maghrebi chaabi / rai / gnawa, afro, trap / drill, RnB, jazz and fusions.
  • Real keywords: YouTube search suggestions (A→Z) in the country and language of the style heard, optional real monthly volumes imported from Google Keyword Planner, competition score from the YouTube Data API, Google Trends links.
  • Writes the SEO pack: 6–12 scored titles with different hooks, A/B titles for “Test & compare”, description with a valid chapter timeline (00:00 Intro … 00:45 🔥 Chorus), 25–40 tags within 500 characters, 3–5 trending hashtags, pinned comment, thumbnail texts and a Short to cut.
  • Fills YouTube Studio automatically: the old title, description and tags are deleted and replaced (option), never what you type during the analysis; a comment to pin is ready to copy. YouTube policies are checked before you publish.
  • Competitor tracking (outlier videos, best hours, top tags), trends, history, three interface languages (English, French, Arabic with right-to-left layout), light and dark themes.

Install

From the Chrome Web Store

Click Add to Chrome. The settings page opens with a 4-step checklist.

From the package (developer mode)

  1. Unzip tubepilot-5.x.x.zip.
  2. Open chrome://extensions, enable Developer mode.
  3. Click Load unpacked and select the tubepilot folder (the one containing manifest.json).
  4. Pin the TubePilot icon in the toolbar: a click opens the side panel.

Requirements: Chrome 116+ (or Edge / Brave based on Chromium 116+), a Google account. No AI Studio / Gemini API key is needed. Optional: a YouTube Data API key, a Google Ads account for Keyword Planner.

Quick start (2 minutes)

  1. Sign in to Gemini once at gemini.google.com (Gemini Advanced / Pro gives the best listening).
  2. Describe your channel in Settings › Channel profiles: genres, languages (e.g. ar, fr), countries (e.g. SA, AE, MA), tone, signature. One profile per channel.
  3. Optional — YouTube API key in Settings › YouTube API for competition, views/hour, trends and competitors.
  4. Upload a video in YouTube Studio. The TubePilot card appears under the title, Gemini listens and the fields are filled. Click another title to use it, or Apply all.

Gemini — your own Google account

TubePilot uses Gemini in your own Google account (gemini.google.com). There is no API key and no AI Studio quota: requests count against your Gemini plan like any conversation you have with Gemini.

  1. TubePilot opens Gemini in a small window in the corner of the screen (or a background tab).
  2. It selects the Pro model in Gemini’s model menu (setting Gemini model; choose “Keep the model selected in Gemini” to disable).
  3. It sends the expert master prompt with the public link of the video — or, for a private video, the audio of your file extracted on your computer (16 kHz WAV) and attached to the chat.
  4. If Gemini does not open the link the first time, TubePilot asks again in the same conversation.
  5. It reads Gemini’s JSON answer, sends a second request with the real YouTube searches (2-step mode), fills YouTube Studio and closes the window.

TubePilot drives the Gemini web page inside your own browser session. If Google changes that page, use Manual mode (copy / paste) in the side panel until an update is published.

The master prompt

Gemini works as a panel of four experts — YouTube growth strategist, international ethnomusicologist, YouTube & Google SEO specialist and hook copywriter. It listens to the whole song, then delivers: 6–12 titles made for YouTube (40–70 characters, hook and keyword in the first 40, 1–2 emotion emojis, the audience’s dialect), a description whose first two lines rank in search, a timeline of the song with the best moments marked 🔥, 25–40 tags, 3–5 hashtags and a comment to pin.

Two steps or one

2 steps (recommended): Gemini listens first; TubePilot then researches real YouTube searches in the style’s country and sends a second request in the same conversation. 1 step is faster but uses fewer real keyword data.

In YouTube Studio

  • The card sits at the top of the Details form, above the Title (upload dialog or video edit page). After every insertion TubePilot checks that Studio’s layout is intact.
  • Analyze with Gemini: listens to the uploaded file (captured when you choose it in Studio) or to the public link. Choose the file if the video was uploaded earlier. Quick: no listening, a few seconds.
  • Tabs: Titles (score, hook type — click to apply), Description, Tags, Comment, Insights (style, BPM, best moments, keyword demand and competition), Rules (policy checks).
  • Autopilot (setting): analysis starts as soon as a video is uploaded. Replace the old title, description and tags (on by default): the old description and old tags are deleted and replaced; turn it off to fill only empty fields. What you type during the analysis is never overwritten. On an existing video, click Save in Studio afterwards.
  • Comment tab: the comment to pin (a question + the best moment with its timestamp). Copy it, post it under the video, then ⋮ › Pin.
  • While typing tags, popular YouTube searches are suggested.
  • On any YouTube video page, a card shows views/hour, outlier score, hooks, tags and chapters, with Analyze with Gemini.

Google Keyword Planner volumes

Google does not offer a free Keyword Planner API (it requires a Google Ads developer token). TubePilot therefore imports the CSV export:

  1. Open Keyword Planner → Discover new keywords, type your genres, artists and song themes, choose the country and language.
  2. Download keyword ideas → CSV (UTF-16 tab-separated) or Google Sheets → File › Download › CSV.
  3. In Settings › Keyword Planner (or the Keywords tab), click Import CSV. Several files at once are fine (one per country).

Headers in English, French, Spanish, Italian, German, Portuguese and Arabic are recognised; volume ranges such as 1K – 10K, 1 k – 10 k or ١٠ آلاف - ١٠٠ ألف are understood. From then on, the Volume column appears in keyword research, the ranking blends real volume with YouTube popularity, and Gemini receives the volumes in its SEO request.

Keyword Planner measures Google Search volume, not YouTube search. It is an excellent demand signal for music queries; TubePilot combines it with real YouTube suggestions and competition.

YouTube rules applied

  • Title ≤ 100 characters, no < >, no all-caps or “!!!”, no misleading promises, “Official” only for official artist channels.
  • Description ≤ 5,000 characters, no keyword stuffing or keyword lists, no link shorteners.
  • Tags ≤ 500 characters (counted like YouTube: quotes for tags with spaces, commas), no duplicates, no absent artists or brands.
  • Hashtags: 3–5 recommended; over 15 YouTube ignores them all.
  • Chapters: first at 00:00, at least 3, each ≥ 10 seconds.
  • Reminders for altered or synthetic content (realistic AI) and covers (credit and Content ID).

The checks help you follow YouTube’s spam, deceptive practices & scams policy; you remain responsible for your uploads.

Troubleshooting

“TubePilot was updated: reload this page”Reload the YouTube / Studio tab (F5) after installing or updating the extension.
The Gemini window asks me to sign inSign in inside that window; TubePilot continues by itself. For another Google account, paste its Gemini address (e.g. https://gemini.google.com/u/1/app) in Settings › AI engine.
“Drag the audio file into Gemini”Gemini refused the automatic attachment: drag the file shown, TubePilot then continues.
No timelineThe video was not listened to (quick mode, private video without file). Choose the file and analyze again.
Tags field not foundClick “Show more” on the Studio Details page.
YouTube quota reachedThe free quota (10,000 units/day) resets at midnight Pacific time. Disable “Compare keywords” to save quota.

FAQ

Does TubePilot listen to private videos?

Yes, from the file you upload in Studio (or choose): the audio is extracted on your computer and sent only to Gemini. Public and unlisted videos can also be analysed by link.

Where is my data stored?

In your browser only. See the privacy policy.
