SEO YouTube piloté par Gemini — réglages

1. Clé Gemini (obligatoire pour l'écoute automatique)

Gratuite : ouvrez aistudio.google.com/apikey → « Create API key » → copiez la clé (commence par « AIza »). C'est grâce à l'API que Gemini écoute et regarde le fichier lui-même, même quand la vidéo est privée. Votre abonnement Gemini Pro reste utilisable en mode manuel (panneau › « Mon abonnement Gemini Pro »).

Conseil : un modèle « Pro » analyse mieux la musique ; en quota gratuit, un modèle « Flash » permet beaucoup plus de vidéos par jour. La liste vient directement de votre compte Google.

2. Clé YouTube Data API v3 (concurrents, tendances, statistiques)

Gratuite : activez « YouTube Data API v3 », puis Identifiants → « Créer des identifiants » → « Clé API ». Quota : 10 000 unités par jour (une analyse de concurrence ≈ 102 unités, tout est mis en cache).

4. Profils de chaînes

Chaque chaîne a sa langue, son public et ses règles. Dans Studio, le profil est choisi automatiquement grâce à l'ID de la chaîne (UC…, visible dans l'adresse de Studio).

5. Sauvegarde

Confidentialité & règles

Vos clés restent dans Chrome (stockage local de l'extension). Le fichier vidéo est lu sur votre ordinateur puis envoyé uniquement à Google (API Gemini) pour l'analyse. Les métadonnées générées suivent le règlement YouTube : pas de titres trompeurs, pas de bourrage de mots-clés, tags ≤ 500 caractères, 3 à 5 hashtags, chapitres valides, mention « contenu synthétique » rappelée quand c'est utile.
